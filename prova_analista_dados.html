Prova Pratica - Analista de Dados

Vaga: Analista de Dados | ETL + Power BI + Data Mining

IMPORTANTE: Leia todas as etapas. Execute TODAS as etapas e entregue os artefatos listados. Tempo estimado: 2-3 horas.

Entregaveis Obrigatorios

Entregar no GitHub:

  • 1. Repositorio GitHubpublico com todo o codigo
  • 2. Script ETL funcional (Python)
  • 3. Banco de dados com dados processados
  • 4. Resultados das queries analiticas
  • 5. Arquivo .pbix do Power BI
  • 6. Screenshot do dashboard
  • 7. README.md completo

Passo a Passo

1 Preparar Ambiente

  1. Criar pasta de trabalho (ex: C:\Users\SEU_NOME\prova-dados)
  2. Instalar Python 3.8+: python.org
  3. Instalar Power BI Desktop: powerbi.microsoft.com
  4. Criar conta no GitHub: github.com

2 Criar Repositorio GitHub

  1. Acessar github.com e fazer login
  2. Clicar em "New repository"
  3. Nome: prova-analista-dados-SEUSOBRENOME
  4. Selecionar "Public"
  5. Marcar "Add a README file"
  6. Clicar em "Create repository"
PRONTO: Anote o link!

3 Clonar e Configurar

  1. Abrir terminal/cmd
  2. Navegar para pasta:
cd C:\Users\SEU_NOME\prova-dados
  1. Clonar repositorio:
git clone https://github.com/seuusuario/prova-analista-dados-seunome.git
  1. Copiar scripts: etl.py, conexao.py, queries.py, requirements.txt

4 Baixar Dataset

  1. Escolher dataset de:
    • Kaggle
    • UCI Machine Learning
  2. Ou usar comando:
python -c "import pandas as pd; df = pd.read_csv('https://raw.githubusercontent.com/datasets/advertising/master/data/advertising.csv'); df.to_csv('dados_originais.csv', index=False)"

5 Executar ETL

  1. Instalar dependencias:
pip install -r requirements.txt
  1. Executar ETL:
python etl.py dados_originais.csv dados.db
  1. Verificar se criou dados.db

6 Executar Queries

  1. Executar:
python queries.py
  1. Verificar resultados.txt criado

7 Criar Dashboard Power BI

  1. Abrir Power BI Desktop
  2. Obter Dados > SQLite > dados.db
  3. Selecionar tabela: vendas
  4. Clicar Carregar
Criar visualizacoes:
  • 1 Card (KPIs)
  • 1 Grafico de Barras
  • 1 Grafico de Pizza/Rosca
  • 1 Grafico de Linha
  • 1 Tabela
  • 1 Filtro (Slicer)
  1. Salvar: dashboard.pbix
  2. Exportar imagem: dashboard.png

8 Entregar no GitHub

  1. Adicionar arquivos:
git add . git commit -m "Prova concluida" git push
  1. Atualizar README.md com descricao, link, resultados, screenshot
  1. Push do README:
git add README.md git commit -m "Documentacao final" git push
